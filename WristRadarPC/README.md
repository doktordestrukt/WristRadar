# WristRadar PC

A Windows companion that acts as a WristRadar "watch". Your PC can pair with a Galaxy Watch running
WristRadar and chat with it over **direct Bluetooth LE**. It uses the same end-to-end encryption, byte for byte:
X25519 + ML-KEM-768 hybrid handshake, Ed25519 identities, AES-256-GCM, and SAS code pairing.

## Run

`dist/WristRadarPC.exe`. It needs Windows 10 2004+ / 11, a Bluetooth LE adapter, and the .NET 10 Desktop Runtime,
which is already on this PC.

## Use

1. On the watch, open WristRadar → **Connect to nearby watches**.
2. On the PC, open **Nearby watches**, select the watch, then click **Pair with selected watch**.
3. Accept on the watch, then compare the 6-digit codes. Click **Codes match** on both.
4. Use the **Chat** tab: type and press Enter, or **Picture…** to send an image. Pictures and avatars from the watch show up here.
5. Afterwards the PC reconnects automatically whenever the watch is in range. The watch does not need to be on any
   particular screen. **Refresh connection** forces a retry.

There's also a Security log, a BLACKBOX alert preview, a sound/music toggle, and Unpair.

## How it differs from a second watch

- **The PC always connects to the watch, never the other way round.** Windows' BLE peripheral and advertising support is
  unreliable across adapters, so the PC only scans and connects. Because of this the watch can't list the PC on its
  Nearby screen. You start pairing from the PC, and the watch shows the request.
- **Your data is protected with Windows DPAPI.** Keys, history and pictures live in `%APPDATA%\WristRadarPC`, encrypted
  for your Windows user account. Unpair wipes the keys and the conversation.
- **There's a diagnostics log.** `%APPDATA%\WristRadarPC\debug.log` records connection phases and errors only, never
  message content or keys.
- **Distance is rough.** It comes from the watch's advert signal strength, which is only seen while not connected.

## Self-test

```bash
dist/WristRadarPC.exe --selftest result.txt
```
This checks the PC's crypto against known answers generated by the watch's Kotlin code: Ed25519, X25519, HKDF,
AES-GCM, advert tokens, and the ML-KEM round trip. All 11 checks pass.

## Build

```bash
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o dist
```
